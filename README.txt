DESAFIO APROVAÇÃO V10

Abra o arquivo index.html em um navegador moderno. O projeto funciona localmente e salva o progresso no próprio navegador usando localStorage.

Principais recursos:
- Vestibulares, concursos públicos, bancas, anos, editais e treinos temáticos mantidos da V9.
- Painel de estudo reorganizado: modos, desempenho, filtros, meta diária e controles de progresso ficam próximos.
- Histórico de respostas: guarda pergunta, sua resposta, gabarito, explicação, matéria, modo e data.
- Filtros do histórico por todas, acertos ou erros.
- Reset separado de XP e de desempenho. O histórico de respostas não é apagado nesses resets.
- Correção no sistema de XP para impedir que uma mesma partida seja contabilizada mais de uma vez ao finalizar.
- Sanitização das estatísticas salvas para recuperar valores inválidos ou corrompidos.
- Rotação anti-repetição e variações de enunciado continuam ativas.
- Layout responsivo atualizado, com navegação mais clara em celular.

Arquivos principais:
index.html
style.css
script.js
questions.js
real-questions.js
extra-real-questions.js
edital-questions.js
more-edital-questions.js
public-exams.js
editais.js

Observação: os dados de progresso e histórico ficam no navegador/dispositivo em que o site foi aberto.
